진주 달콤한 하루 - 디저트 & 베이킹 페스타 데모 웹사이트

실행 방법
1. 압축을 풉니다.
2. jinju-dessert-festa 폴더의 index.html을 브라우저에서 엽니다.
3. 사전등록 버튼은 registration.html로 이동합니다.

파일 구성
- index.html : 행사 메인 페이지
- registration.html : 사전등록 및 시식/클래스 신청 데모 페이지
- css/style.css : 메인 페이지 스타일
- css/registration.css : 신청 페이지 스타일
- js/main.js : 메뉴, 일정 팝업, 프로그램 팝업
- js/modal.js : 팝업 기능 분리 예시 파일
- js/registration.js : 신청 폼 처리
- assets/ : PNG 및 JPG 형식의 디저트 일러스트 이미지

참고
이 사이트는 웹 제작 연습용 가상 행사입니다. 2027년 날짜, 진주 남강변 행사장, 브랜드, 프로그램, 참가비는 모두 예시입니다.
신청 폼은 서버나 DB에 연결되지 않으며 브라우저에서 데모 완료 팝업만 표시합니다.
Google Fonts는 인터넷 연결 시 적용됩니다.

이미지 경로 수정 안내
- index.html의 이미지 경로를 assets 폴더의 실제 파일명 및 확장자와 일치시켰습니다.
- 메인 배너와 케이크 이미지는 PNG, 쿠키·소금빵·음료 이미지는 JPG를 사용합니다.
